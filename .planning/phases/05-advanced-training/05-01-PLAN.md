pip install optuna optuna-integration[xgboost]

Create scripts/train_advanced.py with these sections:

**Imports and setup:**
- Import from build_differentiator_features: FEATURE_COLS_V2, CATEGORICAL_COLS_V2, TARGET_COL, load_featured_v2
- Import optuna, optuna_integration.XGBoostPruningCallback, sklearn.model_selection.TimeSeriesSplit
- Set MODELS_DIR = Path("models"), seed=42

**Data loading:**
- Load train/val/test via load_featured_v2()
- Create full training array by concatenating train+val for CV (Optuna needs to do its own splits)
- Keep test separate (never touched during tuning)
- Store test metadata columns (route_id, stops_away, scheduled_time_to_target, distance_to_target, minutes_since_midnight) for sliced eval later

**Optuna objective function:**
- Define `objective(trial)` that suggests:
  - max_depth: int 3-8
  - learning_rate: float 0.01-0.3 (log=True)
  - min_child_weight: int 5-100
  - subsample: float 0.5-1.0
  - colsample_bytree: float 0.5-1.0
  - reg_alpha: float 1e-3 to 10.0 (log=True)
  - reg_lambda: float 1e-3 to 10.0 (log=True)
  - num_boost_round: int 500-5000
- Fixed params: objective="reg:squarederror", eval_metric="mae", tree_method="hist", max_cat_to_onehot=10, seed=42
- Use TimeSeriesSplit(n_splits=4) on the full train+val concatenation
- For each fold: create fresh DMatrix objects (not slicing pre-built DMatrix -- avoids data leakage), train with xgb.train(), use XGBoostPruningCallback(trial, "val-mae"), early_stopping_rounds=50, verbose_eval=False
- Return mean CV MAE across folds

**Study execution:**
- Create study with direction="minimize", pruner=optuna.pruners.MedianPruner(n_startup_trials=10)
- Run study.optimize(objective, n_trials=150, show_progress_bar=True)
- Print best trial params and value
- IMPORTANT: Use timeout=None (let all 150 trials complete)

**Retrain best config on full train set:**
- Take best_params from study
- Create DMatrix from full training data (train split only, NOT train+val -- val is for early stopping)
- Create DMatrix from val split for early stopping
- Train with xgb.train() using best_params, best num_boost_round from trial, early_stopping_rounds=100
- Predict on test set
- Compute MAE, RMSE, MAPE

**Sliced metrics:**
- Reuse the same slicing logic from train_differentiator.py (per-route, per stops_away bucket, per time-of-day, per distance)
- Use identical bucket functions (stops_bucket, tod_bucket, distance_bucket) -- copy them from train_differentiator.py

**Save artifacts:**
- Save model as models/tuned_v1.ubj
- Save models/tuned_metrics.json containing:
  - best_params (the Optuna-selected hyperparameters -- Plan 02 reads this)
  - best_num_boost_round (from best trial)
  - best_cv_mae (Optuna's best trial value)
  - test metrics (mae, rmse, mape)
  - sliced metrics (per_route, per_stops_bucket, per_tod, per_distance)
  - study_summary: n_trials, n_pruned, best_trial_number
  - comparison to Phase 4 differentiator (load differentiator_metrics.json)

**Print summary:**
- Print comparison: Differentiator MAE -> Tuned MAE -> improvement
- Print progressive chain: naive -> baseline -> differentiator -> tuned
- Print gate check: tuned MAE < differentiator MAE

IMPORTANT implementation notes:
- Use xgb.train() native API throughout (NOT sklearn XGBRegressor) -- required for consistency with existing codebase and for Plan 02 custom objectives
- For TimeSeriesSplit CV, the data must be sorted by time. The v2 parquets are already temporally ordered (train is earliest dates, val is next). When concatenating train+val for CV, keep the natural order (train rows first, then val rows).
- Do NOT include penalty ratio or threshold in Optuna search space -- these are fixed business decisions per CONTEXT.md
- The objective function should capture the data arrays via closure (not as arguments) for clean Optuna integration
