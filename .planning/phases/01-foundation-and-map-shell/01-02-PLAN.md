Create src/hooks/useLocation.ts:
- Export a `useLocation` hook that:
  1. On mount, calls `Location.requestForegroundPermissionsAsync()` ONCE
  2. If granted: calls `Location.getCurrentPositionAsync()` to get initial position, then starts `Location.watchPositionAsync()` with accuracy: Location.Accuracy.Balanced
  3. If denied: silently sets `permissionDenied = true`, no re-prompt, no error, no banner (per user decision)
  4. Returns `{ location: { latitude, longitude } | null, permissionDenied: boolean, loading: boolean }`
  5. Cleans up the watcher subscription on unmount
- Handle the edge case where location services are disabled at the OS level — treat same as denied

Create src/screens/MapScreen.tsx:
- Render `<MapView>` from react-native-maps filling the entire screen (StyleSheet.absoluteFillObject)
- Provider: use default (Apple Maps on iOS, Google Maps on Android per user decision — do NOT set provider="google" explicitly; let it auto-detect)
- Initial region: `{ latitude: 32.606, longitude: -85.487, latitudeDelta: 0.025, longitudeDelta: 0.025 }` — this gives approximately zoom level 14.5 showing the full campus
- Set `rotateEnabled={true}` and `pitchEnabled={true}` (per user decision: two-finger rotate and 3D tilt)
- Set `showsUserLocation={true}` — react-native-maps will show the blue dot only if permission was granted; if denied it silently shows nothing (matching our desired behavior)
- Set `showsMyLocationButton={false}` — we provide our own custom button
- Store a ref to MapView for programmatic animation (used by the location button)
- Pass the mapRef down to child components via props or context
- Render the FloatingLocationButton and GlassBottomBar as absolute-positioned children overlaying the map
- Use `colors.background` from theme tokens as the map container background color (visible briefly during map tile load)

Update App.tsx:
- Replace the placeholder "Tiger Transit" View with MapScreen
- Keep the Redux Provider wrapper and font loading logic from Plan 01
- Ensure SplashScreen.preventAutoHideAsync() is called at module level (before component renders)
- In the component, once fontsLoaded is true, call SplashScreen.hideAsync() — the ~300ms cross-fade is configured via app.json splash config (set "splash.fadeOutDuration" to 300 if supported, otherwise the default expo-splash-screen fade is acceptable)
- Do NOT render MapScreen until fontsLoaded is true — user sees splash -> fonts load -> splash hides -> map appears. No intermediate states.
