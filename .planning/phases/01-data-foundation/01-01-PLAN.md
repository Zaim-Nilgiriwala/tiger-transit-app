  <name>Task 1: Create telemetry parser script</name>
  <files>scripts/parse_telemetry.py, data/processed/telemetry.parquet</files>
  <action>
Create `scripts/parse_telemetry.py` that:

1. **Loads all 52 JSONL files** from `mobile/src/ETA-Model/raw_data/raw_data_*.jsonl`. Parse line-by-line with `json.loads()` (not `pd.read_json` -- need error handling for malformed lines). Process files one at a time, appending to a list of DataFrames, then `pd.concat()` at the end. Print per-file row counts as loading progresses.

2. **Renames columns** to snake_case:
   - `t` -> `timestamp_ms`, `vid` -> `vehicle_id`, `routeId` -> `route_id`, `patternId` -> `pattern_id`
   - `lastStopId` -> `last_stop_id`, `nextStopId` -> `next_stop_id`, `etaSeconds` -> `eta_seconds`
   - `scheduledEta` -> `scheduled_eta_seconds`, `isDelayed` -> `is_delayed`
   - `lastStopTime` -> `last_stop_time_ms`, `lastStopOnTime` -> `last_stop_on_time`
   - Keep `lat`, `lon`, `heading`, `speed`, `load`, `progress` as-is

3. **Converts timestamp**: Add `timestamp` column via `pd.to_datetime(df['timestamp_ms'], unit='ms', utc=True)`. Keep `timestamp_ms` as well for downstream joins.

4. **Applies filters** (vectorized, single mask):
   - Auburn bounding box: lat 32.5-32.7, lon -85.6 to -85.4
   - Speed <= 65 mph
   - Exclude `vehicle_id` containing "jAUnt" or "Shuttle" (case-insensitive) or empty string ""
   - Exclude `pattern_id == 9998` (Not In Service)
   - Exclude `route_id` in [777, 230, 231] and range 216-228 (staging, Charter, Vans, Game Day Shuttle)
   - Exclude rows where `progress == -1` (inactive vehicles)
   - Log counts for each filter step (how many rows removed by each filter)

5. **Prints validation summary**: Total rows loaded, rows after filtering, null rates per column, unique route count, unique vehicle count, date range, rows per day distribution (min/max/mean).

6. **Writes** to `data/processed/telemetry.parquet` (create `data/processed/` directory if needed). Use `index=False`.

Important: Use `pathlib.Path` for all file paths. Define `PROJECT_ROOT` relative to the script location (`Path(__file__).resolve().parent.parent`). The raw data is at `PROJECT_ROOT / "mobile" / "src" / "ETA-Model" / "raw_data"`.
