<task type="auto">
  <name>Task 2: Create arrivals parser script</name>
  <files>scripts/parse_arrivals.py, data/processed/arrivals.parquet</files>
  <action>
Create `scripts/parse_arrivals.py` that parses arrivals CSVs and maps station names to numeric GTFS stop IDs.

1. **Load both CSV files** from `mobile/src/ETA-Model/raw_data/` -- there are 2 arrivals CSV files. Use `skiprows=1` to skip the metadata header row. Concatenate both into one DataFrame.

2. **Map station names to GTFS stop IDs**:
   - Load `mobile/src/ETA-Model/stops.json` which contains stop objects with `id` and `name` fields
   - Build `name_to_id` dict: `{stop['name'].strip(): int(stop['id']) for stop in stops}`
   - Map `df['Station'].str.strip()` -> `stop_id` using this dict
   - Log any unmatched stations (research says only "Recruitment Stop" is unmatched -- 1 out of 155)
   - Drop rows with unmatched stop_id (NaN) with a logged warning count

3. **Map route names to numeric route IDs**:
   - Load `data/processed/gtfs_routes.parquet` (created by parse_gtfs.py, but can also fall back to reading `gtfs_data/routes.txt` directly if parquet doesn't exist)
   - Build `route_name_to_id` dict from route_long_name -> route_id_num
   - Map `df['Route']` -> `route_id` using this dict
   - Log any unmatched routes

4. **Parse timestamps**:
   - Combine DATE + ARRIVAL columns into a full datetime: parse DATE as date, parse ARRIVAL as time, combine
   - Handle midnight wrapping: if ARRIVAL time is "0:XX:XX" and the trip appears to be late-night service, it belongs to the previous day. Use heuristic: if time < 3:00 AM, it's likely past-midnight service (keep as-is on the recorded DATE since the arrival file associates it correctly)
   - Create `arrival_timestamp` column as timezone-aware UTC (convert from Central time)
   - Similarly create `departure_timestamp` from DATE + DEPARTURE

5. **Rename columns** to snake_case:
   - `DATE` -> `date`, `Vehicle ID` -> `vehicle_id`, `Number` -> `trip_number`
   - `Route` -> `route_name` (keep original), add `route_id` from mapping
   - `Station` -> `station_name` (keep original), add `stop_id` from mapping
   - `ARRIVAL` -> `arrival_time_str` (keep original string), add `arrival_timestamp`
   - `DEPARTURE` -> `departure_time_str`, add `departure_timestamp`
   - `Dwell (sec)` -> `dwell_seconds`
   - Keep APC Boardings and Alightings columns, rename to snake_case

6. **Filter**: Exclude rows where trip_number is "NIS" (Not In Service). Exclude jAUnt vehicles (vehicle_id containing "jAUnt").

7. **Print validation summary**: Total rows, rows after filtering, unmatched station count, unmatched route count, unique stops, unique routes, date range, rows per day stats.

8. **Write** to `data/processed/arrivals.parquet`.

Note: This script loads gtfs_routes.parquet if it exists for the route mapping, but if it doesn't exist yet (plans run in parallel), fall back to reading `gtfs_data/routes.txt` directly and computing route_id_num the same way parse_gtfs.py does. This makes the script independently runnable.
  </action>
