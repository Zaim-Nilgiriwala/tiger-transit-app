  <action>
Create `scripts/build_features.py` that loads train.parquet, val.parquet, test.parquet and computes all features identically on each split. The script should:

1. Load supplementary data:
   - `data/processed/stop_sequences.parquet` for max_shape_dist per route
   - `data/processed/weather.parquet` for precipitation and temperature

2. Compute features (apply same function to each split):

   **FEAT-01: distance_to_target**
   - Get max_shape_dist per route_id from stop_sequences (groupby route_id, take first/max)
   - Formula: `(target_stop_progress - progress) * max_shape_dist`
   - Clip to >= 0

   **FEAT-02: scheduled_time_to_target**
   - Use `scheduled_eta_seconds` column directly from telemetry as the proxy
   - This is the system's scheduled ETA which captures the scheduled time remaining
   - If values look wrong (check distribution), fall back to a ratio-based approach, but try direct first
   - Clip to >= 0

   **FEAT-03: current_speed, route_progress, stops_remaining, stop_index**
   - `current_speed` = `speed` (direct rename)
   - `route_progress` = `progress` (direct rename)
   - `stops_remaining` = `stops_away` (direct rename)
   - `stop_index` = `target_stop_sequence` (direct rename)

   **FEAT-04: lateness_now**
   - Formula: `scheduled_eta_seconds - eta_seconds`
   - Positive values = running late (scheduled says more time remaining than actual ETA)
   - Log distribution stats (mean, median, std, min, max) to verify sanity

   **FEAT-05: minutes_since_midnight, day_of_week**
   - `minutes_since_midnight` = `timestamp.dt.hour * 60 + timestamp.dt.minute`
   - `day_of_week` = `timestamp.dt.dayofweek` cast to pandas category dtype

   **FEAT-06: pattern_id (categorical)**
   - Cast `pattern_id` to pandas category dtype
   - Also cast `route_id` to category (used as categorical feature)

   **FEAT-07: precipitation_mm, temperature_c**
   - Floor telemetry `timestamp` to nearest hour
   - Merge with weather.parquet on the hour column
   - Weather columns to keep: precipitation (rename to precipitation_mm), temperature (rename to temperature_c)
   - Fill any NaN weather values with 0 for precipitation, median for temperature

   **FEAT-08: passenger_load, is_idle**
   - `passenger_load` = `load` (direct rename)
   - `is_idle` = `(speed <= 2).astype(int)`

3. Define the FEATURE_COLS list (the 14 features that will go into the model):
   ```python
   FEATURE_COLS = [
       "distance_to_target", "scheduled_time_to_target", "current_speed",
       "route_progress", "stops_remaining", "stop_index",
       "lateness_now", "minutes_since_midnight", "day_of_week",
       "route_id", "pattern_id", "precipitation_mm", "temperature_c",
       "passenger_load", "is_idle",
   ]
   CATEGORICAL_COLS = ["day_of_week", "route_id", "pattern_id"]
   TARGET_COL = "time_to_arrival_seconds"
   ```
   Note: 15 feature columns total (the roadmap's "8 core features" maps to 15 individual columns including sub-features).

4. Save each split as `data/processed/{split}_featured.parquet` keeping FEATURE_COLS + TARGET_COL + `stops_away` + `route_id` (for sliced evaluation later).

5. Print summary stats for each split:
   - Row count
   - NaN counts per feature column
   - Feature distribution summary (min, median, max) for key numeric features
   - Unique category counts for categorical features

IMPORTANT: Do NOT use the shap library anywhere. Do NOT install it. SHAP will be handled via XGBoost's native pred_contribs in Plan 02.
