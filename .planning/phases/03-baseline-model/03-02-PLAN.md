<task type="auto">
  <name>Task 2: Create train_baseline.py with training, evaluation, SHAP, and model saving</name>
  <files>scripts/train_baseline.py</files>
  <action>
Create `scripts/train_baseline.py` that does the following:

**1. Load featured data and create DMatrix objects:**
- Load train_featured.parquet, val_featured.parquet, test_featured.parquet
- Import FEATURE_COLS, CATEGORICAL_COLS, TARGET_COL from build_features.py (or redefine them)
- Cast CATEGORICAL_COLS to pandas category dtype BEFORE creating DMatrix
- Create DMatrix for train, val, test with `enable_categorical=True`
- Print shape of each DMatrix

**2. Compute naive baseline:**
- The naive baseline predicts `scheduled_time_to_target` as the ETA
- Compute naive MAE and RMSE on test set: `np.mean(np.abs(y_test - scheduled_time_to_target_test))`
- Print and store naive baseline metrics

**3. Train XGBoost with conservative hyperparameters:**
```python
params = {
    "objective": "reg:squarederror",
    "eval_metric": "mae",
    "tree_method": "hist",
    "max_depth": 5,
    "learning_rate": 0.05,
    "min_child_weight": 30,
    "subsample": 0.8,
    "colsample_bytree": 0.8,
    "reg_alpha": 1.0,
    "reg_lambda": 5.0,
    "enable_categorical": True,
    "max_cat_to_onehot": 10,
    "seed": 42,
}
```
- Train with `xgb.train()`, `num_boost_round=2000`, `early_stopping_rounds=100`
- evals list: `[(dtrain, "train"), (dval, "val")]`
- `verbose_eval=50` to log progress every 50 rounds
- Print best iteration and best validation MAE

**4. Predict on test set:**
- Use `iteration_range=(0, bst.best_iteration + 1)` -- CRITICAL, do not skip this
- Compute test MAE and RMSE
- Print comparison: XGBoost MAE vs naive baseline MAE
- Compute improvement percentage

**5. Sliced metrics:**
- Overall MAE and RMSE
- Per-route MAE (use route_id from test dataframe, not from DMatrix)
- By stops_remaining buckets: 1, 2-3, 4-6, 7+ (use stops_away from test dataframe)
- Print all sliced metrics in a formatted table

**6. SHAP feature importance:**
- Compute SHAP values via `bst.predict(dtest, pred_contribs=True)` -- NOT the shap library
- Shape will be (n_samples, n_features + 1), last column is bias
- Compute mean |SHAP| per feature
- Sort by importance descending
- Print ranked feature importance list
- Verify distance_to_target and scheduled_time_to_target are in top 3 (log warning if not)
- Create matplotlib horizontal bar chart:
  - Title: "Baseline Model - Feature Importance (mean |SHAP|)"
  - Save to `models/shap_summary.png` at 150 DPI
  - Use tight_layout

**7. Save artifacts:**
- Create `models/` directory if not exists
- Save model: `bst.save_model("models/baseline_v1.ubj")` -- MUST use .ubj format (not .bin)
- Save metrics to `models/baseline_metrics.json`:
  ```json
  {
    "model": "baseline_v1",
    "best_iteration": N,
    "hyperparameters": {params dict},
    "naive_baseline": {"mae": X, "rmse": Y},
    "xgboost": {"mae": X, "rmse": Y},
    "improvement_pct": X,
    "per_route": {"route_id": {"mae": X, "n": N}, ...},
    "per_stops_bucket": {"1": {"mae": X, "n": N}, ...},
    "top_features_shap": [["feature_name", shap_value], ...]
  }
  ```

IMPORTANT: Do NOT use the shap library. Use `bst.predict(dmatrix, pred_contribs=True)` for SHAP values.
IMPORTANT: Always use `iteration_range=(0, bst.best_iteration + 1)` for predictions.
IMPORTANT: Save model as .ubj (not .bin) to preserve categorical split information.
IMPORTANT: Keep route_id and stops_away columns accessible from the original test dataframe for sliced evaluation (they may not be in the DMatrix feature set if route_id is already a feature -- handle accordingly).
  </action>
