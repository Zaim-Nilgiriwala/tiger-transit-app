Create a BusMarker component that renders on a react-native-maps MapView as a `Marker` with a custom view.

**Props:**
```typescript
interface BusMarkerProps {
  vehicle: VehiclePosition;
  routeColor: string;  // '#RRGGBB' — looked up by parent
  zIndex: number;      // for z-ordering by timestamp
}
```

**Marker shape (per user decision):**
- Rounded-square container: ~36x36px
- 3 corners have borderRadius = half the side length (~18px) — heavily rounded
- 1 corner (the "pointer") has borderRadius = 0 — sharp 90-degree angle
- The sharp corner points in the direction of travel (heading)
- Container backgroundColor = `routeColor` (the specific route's color)
- 5-8px outline around the container using a brighter tint of routeColor. Create the brighter tint by mixing routeColor toward white at ~30% (simple approach: parse hex, add 30% toward 255 for each channel, clamp at 255). Apply this as a `borderWidth: 3` with `borderColor: brighterTint`.
- Navy-tinted drop shadow consistent with design system: `shadowColor: 'rgba(12, 35, 64, 0.3)'`, `shadowOffset: { width: 0, height: 2 }`, `shadowOpacity: 0.3`, `shadowRadius: 4`, `elevation: 5`

**Heading rotation:**
- The ENTIRE outer container rotates so the sharp corner points in the direction of travel
- Use `transform: [{ rotate: '${heading}deg' }]` on the outer container
- The sharp corner should point "up" (north/0 degrees) by default, so at heading=0 the pointer faces up, at heading=90 it faces right, etc.
- Position the sharp corner at the TOP-LEFT of the square. Then rotation = heading - 45 degrees to make the sharp corner point north at heading=0 (since top-left corner is at -45deg from north). Actually, simpler: place the sharp corner at the TOP of the marker. Use `borderTopLeftRadius: 18, borderTopRightRadius: 18, borderBottomLeftRadius: 18, borderBottomRightRadius: 0`. The bottom-right sharp corner at heading=0 means: container needs rotation = `heading + 135` degrees to point the bottom-right corner north.

Better approach: Place the sharp corner at bottom-center conceptually. Use a rotated square approach:
- The base shape is a square with 3 rounded corners and 1 sharp corner at bottom-right
- Default orientation: sharp corner points DOWN-RIGHT
- To point the sharp corner in the heading direction: rotate by `heading + 135` degrees (since bottom-right is at 135 degrees from north)
- Test: heading=0 (north) -> rotate 135deg -> sharp corner points up. heading=90 (east) -> rotate 225deg -> sharp corner points right. This works.

**Bus icon inside:**
- White bus icon from @expo/vector-icons (Ionicons 'bus' or MaterialCommunityIcons 'bus'). Use Ionicons 'bus' at ~18px size, color white.
- The icon must NOT rotate with the container — apply a counter-rotation: `transform: [{ rotate: '-${heading + 135}deg' }]` to keep the icon upright at all times.

**Implementation notes:**
- Use react-native-maps `Marker` component with `coordinate={{ latitude: vehicle.lat, longitude: vehicle.lon }}`
- Use `tracksViewChanges={false}` for performance (markers update position via coordinate prop, not re-rendering children). Set `tracksViewChanges={true}` only if visual state changes (we can keep it false since color/heading update via re-render when vehicle data changes — actually set it to `false` after initial render using a useEffect timer pattern, or just keep `false` since the Marker coordinate prop handles position updates without re-rendering children).
- Set `anchor={{ x: 0.5, y: 0.5 }}` to center the marker on the GPS position
- Pass `zIndex` prop directly to Marker for z-ordering

**Helper function `brightenColor(hex: string, amount: number): string`:**
Parse hex color, increase each RGB channel toward 255 by `amount` fraction (0.3 = 30%), return as hex string.

const routeColorMap = useMemo(() => {

  routes.forEach(r => map.set(r.routeId, r.routeColor));
  return map;
}, [routes]);

    zIndex={vehicle.timestamp}

))}
