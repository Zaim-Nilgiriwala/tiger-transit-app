Implement `mapRowToVehiclePosition(row: any): VehiclePosition` helper:
- Map snake_case DB columns to camelCase TS fields:
  - `vehicle_id` -> `vehicleId`, `route_id` -> `routeId`, `lat` -> `lat`, `lon` -> `lon`
  - `heading` -> `heading`, `speed` -> `speed`, `load` -> `load`, `capacity` -> `capacity`
  - `next_stop_id` -> `nextStopId`, `eta_seconds` -> `etaSeconds`, `on_time` -> `onTime`
  - `last_stop_id` -> `lastStopId`, `is_delayed` -> `isDelayed`, `timestamp` -> `timestamp`

Implement `export function useVehicleSubscription(): { isConnected: boolean }`:

1. `fetchSnapshot()` callback:
   - `await supabase.from('vehicles').select('*')`
   - On success: filter by stale threshold (`Date.now() - row.timestamp < STALE_THRESHOLD_MS`), map with `mapRowToVehiclePosition`, dispatch `setPositions`, dispatch `setConnected(true)`
   - On error: dispatch `setConnected(false)` but do NOT clear positions (keep last known)

2. `subscribe()` callback:
   - Call `fetchSnapshot()` immediately (covers any missed updates)
   - Create channel: `supabase.channel('vehicles-realtime').on('postgres_changes', { event: '*', schema: 'public', table: 'vehicles' }, () => fetchSnapshot()).subscribe((status) => { ... })`
   - On `SUBSCRIBED` status: dispatch `setConnected(true)`
   - On `CHANNEL_ERROR` or `TIMED_OUT`: dispatch `setConnected(false)`
   - Store channel in `channelRef`

3. `unsubscribe()` callback:
   - If `channelRef.current` exists, call `supabase.removeChannel(channelRef.current)` and null the ref

4. `useEffect`:
   - Call `subscribe()` on mount
   - Set up AppState listener:
     - On `active`: clear stale positions from Redux (same pattern as useGtfsPolling -- use `store.getState().vehicles.positions`, filter by STALE_THRESHOLD_MS, dispatch filtered list), then call `subscribe()` (which fetches fresh snapshot + resubscribes)
     - On `background`/`inactive`: call `unsubscribe()`
   - Cleanup: `unsubscribe()` and remove AppState listener

5. Return `{ isConnected }`
