  **1. Create `useAnimatedPosition` hook** in `src/hooks/useAnimatedPosition.ts`:

  The hook implements a playback buffer approach: bus positions are displayed ~15 seconds behind real time so there is always a "next position" to animate toward.

  **Interface:**
  ```typescript
  function useAnimatedPosition(
    vehicle: VehiclePosition,
    routeShape: Coordinate[] | undefined,
    visible: boolean,
  ): {
    latitude: number;
    longitude: number;
    heading: number;
    isAnimating: boolean;
  }
  ```

  **Internal state (useRef):**
  - `prevPosition`: `{ lat, lon, timestamp, shapeIndex, shapeFraction }` -- the previous known position projected onto the polyline
  - `currPosition`: same shape -- the latest known position projected onto the polyline
  - `animStartTime`: `number` -- when the current animation started (Date.now())
  - `animDuration`: `number` -- how long to animate (based on real time delta between positions)

  **Logic on each vehicle update** (detect via `vehicle.lat`/`vehicle.lon`/`vehicle.timestamp` changing):
  1. Project the new `{latitude: vehicle.lat, longitude: vehicle.lon}` onto `routeShape` using `projectOntoPolyline`
  2. If no `prevPosition` exists (first appearance), set both prev and curr to the projected point, set `animDuration = 0` (no animation, just place it)
  3. If `prevPosition` exists:
     - Compute `timeDelta = vehicle.timestamp - currPosition.timestamp` (in ms)
     - If `timeDelta > 30_000` (gap threshold -- 2 missed cycles): set prev = curr, curr = new projected point, `animDuration = 1000` (simple 1s lerp fallback)
     - Otherwise: set prev = curr (snap prev to where curr was), curr = new projected point, `animDuration = Math.min(timeDelta, 15_000)` (cap at 15s to avoid ultra-slow crawls)
     - Set `animStartTime = Date.now()`

  **Animation frame loop** using `requestAnimationFrame` (not Reanimated -- need to update Marker coordinate prop which is a plain object, not an Animated.Value):
  - Each frame: compute `t = clamp((Date.now() - animStartTime) / animDuration, 0, 1)`
  - If `routeShape` exists and both prev/curr have valid `shapeIndex`: interpolate along polyline using `interpolateAlongPolyline` and derive heading from `tangentAtPoint`
  - If no routeShape (shouldn't happen in normal operation, but defensive): simple linear lerp between prev and curr lat/lon, heading from bearing between the two points
  - When `t >= 1`: stop requesting frames, set `isAnimating = false`
  - Store result in state: `{ latitude, longitude, heading, isAnimating }`

  **Cleanup:** Cancel animation frame on unmount or when `visible` becomes false.

  When `visible` is false, skip all animation -- just return the raw vehicle position. This avoids wasted computation for hidden markers.
