<objective>
Build the complete baseline computation pipeline that produces historical baseline ETAs and residual labels for all data splits.

Purpose: Phase 7 is the foundation of the v1.1 model reapproach. Without baseline_eta and residual columns in the augmented parquets, Phase 8 (training) and Phase 9 (evaluation) cannot proceed. This plan delivers the entire baseline infrastructure in a single script with built-in diagnostic validation.

Output: `scripts/build_baselines.py` that computes stop-to-stop average baselines (BASE-01), segment-median-sum baselines (BASE-02), blends them 50/50 (BASE-03), generates residual labels (BASE-04), and produces a diagnostic report with fail-fast MAE checkpoint (BASE-05). Augmented parquets written back to `data/processed/{train,val,test}.parquet` with two new columns: `baseline_eta` and `residual`.
</objective>

Create `scripts/build_baselines.py` -- a standalone Python script that computes baseline ETAs and residual labels.

IMPORTANT DECISIONS (locked -- do not change):
- Fallback hierarchy: Tier 1 -> Tier 2 -> Tier 3, MIN_OBS=5 for each tier
- 50/50 blend of stop-to-stop and segment-median-sum baselines
- day_type = is_weekday.astype(int) (binary weekday/weekend)
- No fallback_tier column in output
- Augment existing {split}.parquet files in place (add baseline_eta and residual columns)
- Diagnostic report printed to stdout (notebook cell output)

STRUCTURE (follow existing codebase conventions from build_differentiator_features.py):

1. **Constants section:**
   - DATA_DIR = Path("data/processed")
   - MIN_OBS = 5
   - SPLITS = ["train", "val", "test"]

2. **Helper: add_ct_hour(df)** -- reuse pattern from build_differentiator_features.py line 243:
   `df["hour_ct"] = (df["timestamp"] - pd.Timedelta(hours=6)).dt.hour`

3. **Stop-to-Stop Lookup Tables (BASE-01):**
   Build THREE tier lookup tables from train.parquet ONLY (no val/test data -- data leakage prevention):

   - Tier 1: groupby (route_id, last_stop_id, target_stop_id, hour_ct, day_type), agg mean of time_to_arrival_seconds, filter count >= MIN_OBS
   - Tier 2: groupby (route_id, last_stop_id, target_stop_id, day_type), agg mean, filter count >= MIN_OBS
   - Tier 3: Per-(route_id, day_type) average seconds_per_shape_dist_unit. Compute by merging train with stop_sequences to get shape_dist for last_stop_id and target_stop_id, then seconds_per_unit = time_to_arrival_seconds / (target_shape_dist - current_shape_dist) where dist > 0. Aggregate median per (route_id, day_type). For rows with last_stop_id=0 (not in stop_sequences), compute distance from progress columns: dist = (target_stop_progress - progress) * max_shape_dist.

4. **Apply S2S Fallback to all splits:**
   For each split (train, val, test):
   - Load parquet, add hour_ct and day_type columns
   - Left merge Tier 1 on (route_id, last_stop_id, target_stop_id, hour_ct, day_type) -> baseline_s2s
   - Assert len(df) == n_before after merge (row-count-preserving pattern)
   - For NaN rows, fill from Tier 2 via merge on (route_id, last_stop_id, target_stop_id, day_type)
   - For still-NaN rows, fill from Tier 3: merge tier3 lookup on (route_id, day_type) to get seconds_per_unit, then compute distance for each row (using stop_sequences shape_dist or progress columns for last_stop_id=0), multiply distance * seconds_per_unit
   - Print tier coverage stats: "Tier 1: X%, Tier 2: Y%, Tier 3: Z%, Still NaN: W%"

5. **Segment-Median-Sum Baseline (BASE-02):**
   Build segment median lookup from train.parquet (unique pings with stop transitions, same approach as build_differentiator_features.py compute_historical_segments but with MIN_OBS=5):

   - Extract unique pings from train, compute GPS-derived segment travel times between consecutive stop transitions within (vehicle_id, route_id) groups
   - Actually, SIMPLER approach: Since we already have time_to_arrival_seconds for each (last_stop_id, target_stop_id) pair, and stop_sequences gives us the ordered path, we can compute segment medians directly from the stop-to-stop travel times for adjacent stops. For any (route_id, from_stop, to_next_stop) where stops are adjacent in stop_sequences, the travel time for that segment = the time_to_arrival_seconds when target_stop_id == next_stop AND last_stop_id == from_stop AND stops_away == 1.
   - Apply tiered fallback WITHIN segments:
     * Tier A: (route_id, last_stop_id, hour_ct, day_type) median, count >= 5
     * Tier B: (route_id, last_stop_id, day_type) median, count >= 5
     * Tier C: (route_id, last_stop_id) median, count >= 5
     * If still NaN: skip segment in sum (contributes 0)
   - Build cumulative sum table: For each (route_id, hour_ct, day_type), create ordered array of segment medians along stop_sequence. Compute cumsum.
   - For each row: segment_sum = cumsum[target_stop_sequence_idx] - cumsum[last_stop_sequence_idx]
   - Where sequence indices are looked up from stop_sequences

6. **Blend Baselines (BASE-03):**
   - baseline_eta = (baseline_s2s + baseline_seg_sum) / 2
   - Where one is NaN and other is not: use the non-NaN one
   - Where both are NaN: this should be extremely rare; if it happens, use Tier 3 s2s value (should already be filled)
   - Assert zero NaN baseline_eta values (or report how many remain)

7. **Residual Labels (BASE-04):**
   - residual = time_to_arrival_seconds - baseline_eta
   - Assert training-set residual mean is within +/-30s of zero

8. **Write Augmented Parquets:**
   - For each split, read original parquet, add baseline_eta and residual columns, write back
   - Use the existing pattern: pd.read_parquet -> add columns -> to_parquet with same path
   - Print row counts before and after to verify no data loss

9. **Diagnostic Report (BASE-05):**
   Print comprehensive diagnostic output (this IS the report -- no separate file):

   a. **Overall MAE for all three methods separately:**
      - S2S-only MAE on test
      - Segment-sum-only MAE on test
      - Blended (50/50) MAE on test

   b. **Per-route breakdown table:**
      Route | N | S2S MAE | SegSum MAE | Blend MAE
      (sorted by route_id)

   c. **Error distribution histogram:**
      Using matplotlib, plot histogram of (time_to_arrival_seconds - baseline_eta) on test set
      Bins: np.arange(-2000, 2000, 20) for 20-second bins
      Save to stdout description (since Context says "notebook cell output", use plt.show() or save inline)
      Actually save as models/diagnostics/baseline_error_dist.png for reference

   d. **Time-of-day breakdown:**
      TOD bucket (morning/midday/afternoon/evening) | N | Blend MAE

   e. **Residual statistics:**
      Train mean, val mean, test mean of residual column
      Confirm train mean is within +/-30s of zero

   f. **Fallback tier summary:**
      Overall percentage of rows hitting each tier across all splits

PATTERNS TO FOLLOW (from existing codebase):
