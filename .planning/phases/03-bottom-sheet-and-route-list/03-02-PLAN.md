**Layout (per user decisions):**
The card is a horizontal row with:
1. A 4px wide vertical bar on the left edge in `route.routeColor`
2. The rest of the card content with a subtle tinted background

**Card styling:**
- Container: `surfaces.level2` (#FFFFFF) base, `cardRadius` (8px) border radius, NO border lines
- The 4px left stripe: `position: absolute, left: 0, top: 0, bottom: 0, width: 4, borderTopLeftRadius: cardRadius, borderBottomLeftRadius: cardRadius, backgroundColor: route.routeColor`
- Tinted background: Apply a View over the card with `backgroundColor: route.routeColor` at ~6% opacity (`0F` hex = ~6%). Use a computed rgba: parse the hex routeColor and set alpha to 0.06. Helper function: `hexToRgba(hex: string, alpha: number): string` — strip '#', parse R/G/B, return `rgba(R,G,B,alpha)`.
- Card padding: `cardPadding` (16px) on all sides, with extra `paddingLeft: cardPadding + 4` (account for the stripe width)
- Minimum touch target: The card itself is the tap target, so ensure minimum height of 44px via `minHeight: MIN_TAP_TARGET`

**Text layout (compact two-line per user decision):**
- Line 1 (primary): Route long name in `typography.titleMD` (Manrope Medium 18pt), color `textColors.onSurface`
- Line 2 (secondary): Short name in parentheses + bus count, in `typography.bodyMD` (Inter Regular 14pt), color `textColors.onSurfaceVariant`
  - Format: `"(Route shortName)  ·  2 buses active"` or `"(Route shortName)  ·  No active buses"`
  - The dot separator (middle dot `\u00B7`) between short name and bus count
  - When busCount is 0, bus count text uses `textColors.onSurfaceVariant` (already muted) — per ERR-02
  - When busCount is 1, text says "1 bus active" (singular)
  - When busCount > 1, text says "N buses active" (plural)

**Inactive state (ROUTE-04 + ERR-02):**
- When `busCount === 0`, the entire card gets `opacity: 0.5`
- The card is still tappable (for Phase 4 route detail even when inactive)

**Pressable feedback:**
- Wrap in `Pressable` with `onPress` prop
- On press, reduce opacity slightly: `pressed && { opacity: busCount === 0 ? 0.35 : 0.7 }`

**Use React.memo** on RouteCard since the list re-renders every 5 seconds when vehicle positions update and most cards won't change.

**Part A: Create `src/components/sheet/RouteList.tsx`**

This component reads routes and vehicle positions from Redux, computes bus counts per route, sorts alphabetically, and renders the sectioned list.

**Data derivation (useMemo):**
1. Read `routes` from `state.routes.list` via useAppSelector
2. Read `positions` from `state.vehicles.positions` via useAppSelector
3. Compute `busCountMap: Map<string, number>` — count vehicles per routeId from positions array:
   ```typescript
   const busCountMap = useMemo(() => {
     const map = new Map<string, number>();
     positions.forEach(v => map.set(v.routeId, (map.get(v.routeId) || 0) + 1));
     return map;
   }, [positions]);
   ```
4. Sort routes alphabetically by `longName` using `useMemo`:
   ```typescript
   const sortedRoutes = useMemo(() =>
     [...routes].sort((a, b) => a.longName.localeCompare(b.longName)),
     [routes]
   );
   ```

**Layout:**

```
<View style={container}>

  {sortedRoutes.map(route => (

  ))}
</View>
```
