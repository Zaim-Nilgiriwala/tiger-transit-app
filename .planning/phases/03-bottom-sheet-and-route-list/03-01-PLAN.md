<task type="auto">
  <name>Task 1: Create BottomSheet component with gesture-driven drag and three snap points</name>
  <files>src/components/sheet/BottomSheet.tsx</files>
  <action>
Create a new `src/components/sheet/BottomSheet.tsx` component that implements a draggable bottom sheet using react-native-gesture-handler (GestureDetector + Gesture.Pan()) and react-native-reanimated (useSharedValue, useAnimatedStyle, withSpring, runOnJS).

**Snap points (compute from screen height via useWindowDimensions):**
- collapsed: screen height - 80 (showing ~80px)
- half: screen height * 0.55 (showing ~45%)
- full: screen height * 0.10 (showing ~90%)

The shared value `translateY` drives the sheet position. On pan gesture end, snap to the nearest snap point using `withSpring` with a natural spring config (damping ~20, stiffness ~150 — adjust for feel). After spring settles, call `runOnJS` to dispatch `setSheetPosition('collapsed'|'half'|'full')` to Redux via useAppDispatch.

**Structure:**
```
<GestureDetector gesture={panGesture}>
  <Animated.View style={[sheetStyles, animatedStyle]}>
    <BlurView intensity={20} tint="light" style={blurStyles}>
      {/* Grab handle pill: 32px wide, 4px tall, #C4C6CE, centered */}
      <View style={handleRow}>
        <View style={handlePill} />
      </View>

      {/* Collapsed content: search bar + settings (from GlassBottomBar) */}
      <View style={controlsRow}>
        <Pressable style={searchBar} onPress={handleSearchPress}>
          <MaterialIcons name="search" size={20} color={textColors.onSurfaceVariant} />
          <Text style={searchPlaceholder}>Search routes or stops</Text>
        </Pressable>
        <Pressable style={settingsButton} onPress={() => showToast('Coming soon')}>
          <MaterialIcons name="settings" size={24} color={textColors.onSurface} />
        </Pressable>
      </View>

      {/* Scrollable content area (children) */}
      {children}
    </BlurView>
  </Animated.View>
</GestureDetector>
```

**Glassmorphic styling (SHEET-02):**
- Use `glass.sheet` preset values: borderTopLeftRadius 20, borderTopRightRadius 20
- BlurView intensity={20} tint="light" with backgroundColor rgba(255, 255, 255, 0.85)
- Apply `shadows.sheetAbove` to the outer Animated.View
- overflow: 'hidden' on the outer container for the rounded corners

**Grab handle (SHEET-03):**
- Width: 32px, Height: 4px, borderRadius: 2
- backgroundColor: textColors.outlineVariant (#C4C6CE)
- Centered horizontally with marginTop: spacing.s1 (8px)

**Search bar press at half position:**
- When search bar is tapped AND sheet is at half position, animate to full position
- Use the existing `showToast('Coming soon')` for the actual search functionality

**Scroll-vs-drag conflict resolution:**
- The `children` area (where the route list will go in Plan 03-02) should be wrapped in a ScrollView
- When the sheet is at full position and content is scrolled to top, dragging down should first drag the sheet (not scroll content). Use `simultaneousHandlers` or `activeOffsetY` on the pan gesture to coordinate: pan gesture activates when scrolled-to-top and dragging down, otherwise scroll takes priority.
- SIMPLE APPROACH: Accept `children` as a prop. Wrap children in an `Animated.ScrollView` inside the sheet. Disable scroll when sheet is not at full position (scrollEnabled driven by shared value).

**Loading state (ERR-03):**
- Accept `loading` prop (boolean).
- When `loading` is true, show an ActivityIndicator centered in the content area below the controls row.
- When `loading` is false, show children.

**Props interface:**
```typescript
interface BottomSheetProps {
  children: React.ReactNode;
  loading?: boolean;
}
```

**Map interaction (SHEET-05):**
- The sheet is absolutely positioned, so the MapView behind it receives touch events on uncovered areas naturally. The sheet only captures gestures within its own bounds. This means at half position, the top ~55% of the map is fully interactive. No special `pointerEvents` manipulation needed — react-native-gesture-handler handles this correctly.

**Important implementation notes:**
- Import Animated from 'react-native-reanimated' (not from 'react-native')
- The pan gesture context should store the starting translateY so subsequent drags continue from the current position
- Clamp translateY between full snap point and collapsed snap point to prevent over-dragging
- The sheet starts at collapsed position on mount
