**Gap 1 fix — ROUTE-04: Sort inactive routes to bottom**

Update the `sortedRoutes` useMemo to use a two-key sort: active routes first (busCount > 0), then alphabetical within each group. The sort must depend on BOTH `routes` and `busCountMap`:

```typescript
const sortedRoutes = useMemo(() => {
  return [...routes].sort((a, b) => {
    const aActive = (busCountMap.get(a.routeId) || 0) > 0 ? 0 : 1;
    const bActive = (busCountMap.get(b.routeId) || 0) > 0 ? 0 : 1;
    if (aActive !== bActive) return aActive - bActive;
    return a.longName.localeCompare(b.longName);
  });
}, [routes, busCountMap]);
```

This sorts active routes (busCount > 0) first, then inactive routes (busCount === 0), with alphabetical order within each group. The dependency on `busCountMap` ensures re-sort when vehicle positions change.
