<task type="auto">
  <name>Task 1: Implement GPS-derived rolling speed, acceleration, and idle features</name>
  <files>scripts/build_differentiator_features.py</files>
  <action>
Create `scripts/build_differentiator_features.py` with the following components:

1. **Haversine GPS speed computation** (`compute_gps_speed`):
   - Vectorized haversine distance using numpy (see RESEARCH.md code example)
   - Group by (vehicle_id, route_id), shift lat/lon/timestamp to get previous ping
   - Speed = haversine_meters(prev, curr) / delta_seconds
   - Filter: set NaN where delta < 5 seconds (GPS jitter)
   - Cap at 29.06 m/s (65 mph)
   - Set NaN for first ping after gap > 300 seconds (5 minutes) to avoid stale speeds across trip boundaries

2. **Rolling speed windows** (`compute_rolling_speed_features`):
   - Set timestamp as DatetimeIndex
   - Group by (vehicle_id, route_id)
   - For each window in [30s, 60s, 120s, 180s]:
     - Compute rolling mean of gps_speed_mps -> `speed_mean_{N}s`
     - Compute rolling std of gps_speed_mps -> `speed_std_{N}s`
   - Use `min_periods=1` throughout (ping density is ~60s, smaller windows will have 0-1 points)
   - After rolling, use `.droplevel([0, 1])` to flatten the MultiIndex from groupby
   - Reset index to restore timestamp as column

3. **Acceleration** (`compute_acceleration`):
   - Group by (vehicle_id, route_id), shift gps_speed_mps and timestamp
   - acceleration = (speed_curr - speed_prev) / delta_seconds
   - Set NaN where delta < 5 seconds
   - Set NaN for first ping after gap > 300s

4. **Idle detection** (`compute_idle_features`):
   - `is_idle_gps`: binary flag where gps_speed_mps < 0.894 m/s (2 mph)
   - `seconds_idle`: cumulative duration of consecutive idle pings per vehicle-route. Reset when not idle or on trip boundary. Compute by grouping idle streaks and using `transform(lambda x: (x - x.iloc[0]).dt.total_seconds())`.

5. **Unique ping extraction** (`extract_unique_pings`):
   - From any split DataFrame: `df.drop_duplicates(subset=['vehicle_id', 'timestamp']).copy()`
   - Sort by (vehicle_id, route_id, timestamp)
   - CRITICAL: Rolling features MUST be computed on unique pings (~272K for train), NOT on exploded data (1.21M). The exploded data has ~4.4x duplication per ping for different target stops.

6. **Merge back** helper:
   - After computing rolling features on pings, merge back to full exploded DataFrame on (vehicle_id, timestamp)

All timestamps are UTC. Convert to Central Time (UTC-6) where needed for hour-based features using `(timestamp - pd.Timedelta(hours=6))`. However, rolling speed features use raw timestamps (time deltas are timezone-invariant).

Include a `if __name__ == "__main__"` block that, when run standalone, loads train.parquet, extracts unique pings, computes GPS speed + rolling features, and prints summary stats (NaN rates, speed distribution percentiles, feature counts).

<task type="auto">
  <name>Task 2: Compute historical segment travel time and dwell time aggregates</name>
  <files>scripts/build_differentiator_features.py, data/processed/historical_segments.parquet, data/processed/historical_dwells.parquet</files>
  <action>
Add historical aggregate functions to `build_differentiator_features.py`:

1. **Central Time hour extraction** (`add_ct_hour`):
   - `hour_ct = (timestamp - pd.Timedelta(hours=6)).dt.hour`
   - Auburn service hours: ~6am-8pm CT (hours 12-02 UTC)
   - This hour is used for all hour-based aggregations

2. **Segment travel time** (`compute_historical_segments`):
   - Segment = (route_id, last_stop_id) -- last_stop_id is already in data as natural segment identifier
   - Work on unique pings from TRAINING data only (no val/test)
   - For each vehicle-route trajectory: detect when `last_stop_id` changes. Segment traversal time = timestamp of first ping with new last_stop_id minus timestamp of last ping with previous last_stop_id.
   - Group by (route_id, last_stop_id, hour_ct, day_type where day_type = is_weekday column)
   - Compute: median, p25, p75, count
   - Set median/p25/p75 to NaN where count < 10 (MIN_OBS threshold)
   - Output columns: route_id, last_stop_id, hour_ct, day_type, segment_travel_median, segment_travel_p25, segment_travel_p75
   - Save to `data/processed/historical_segments.parquet`

3. **Dwell time at stops** (`compute_historical_dwells`):
   - Dwell = time bus spends at a stop. Define as: consecutive low-speed pings (gps_speed_mps < 0.894 m/s OR NaN speed for first ping) where last_stop_id just changed to a new value.
   - Duration from the last_stop_id change to when speed exceeds threshold approximates dwell.
   - Group by (route_id, stop_id=last_stop_id, hour_ct, day_type)
   - Compute: median, p25, p75, count
   - Set median/p25/p75 to NaN where count < 10
   - Output columns: route_id, stop_id, hour_ct, day_type, dwell_median, dwell_p25, dwell_p75
   - Save to `data/processed/historical_dwells.parquet`

4. **Print summary for both aggregates:**
   - Number of unique segment combos with valid medians vs total
   - Number of unique dwell combos with valid medians vs total
   - Distribution of median values (min, median, max, p25, p75)

CRITICAL: Historical aggregates are computed from training split ONLY. These saved parquets will be merged into train/val/test in Plan 02 as lookup features.

Update the `if __name__ == "__main__"` block to also compute and save historical aggregates after rolling features.
