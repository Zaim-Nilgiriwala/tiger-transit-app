**src/components/sheet/StopRow.tsx:**
- React.memo wrapped component for individual stop in the transit diagram
- Props: { stop: Stop, sequenceNumber: number, routeColor: string, isLast: boolean, isSelected: boolean, etaText: string, onPress: () => void }
- Layout (left to right):
  - Sequence indicator: route-colored filled circle (~24px diameter) with white number text (Label-SM), centered in a ~40px wide column
  - Vertical connecting line: 2px wide in routeColor, runs from bottom of previous indicator to top of this one. Use absolute positioning within the indicator column. isLast=true hides the line below.
  - Text column (flex: 1): stop name in Title-MD (on-surface), ETA text below in Body-MD (on-surface-variant). ETAs formatted as "3 min . 7 min . 12 min" with middle dot separator, or "No buses en route" in muted text.
- Selected state: background tint at ~8% route color opacity (same hexToRgba pattern as RouteCard)
- Pressable with 44pt minimum tap target
- Import hexToRgba from RouteCard.tsx — move it to a shared utility or duplicate it. Since it is a small pure function, export it from RouteCard.tsx by adding the `export` keyword to the existing function declaration.

**src/components/sheet/RouteDetailView.tsx:**
- Props: none (reads all state from Redux)
- Reads from Redux:
  - `state.ui.selectedRouteId` — which route to display
  - `state.routes.list` — find the Route object by routeId
  - `state.routes.stops[routeId]` — ordered Stop[] for this route (from Plan 04-01)
  - `state.vehicles.positions` — all live vehicles, filtered to this routeId
  - `state.ui.selectedStopId` — which stop is highlighted
- Layout:
  - Sticky header (View, not in ScrollView):
    - 4px left stripe in routeColor (same pattern as RouteCard)
    - Tinted background at ~8% routeColor opacity
    - Back arrow (Ionicons 'chevron-back') on the left — dispatches selectRoute(null) to return to route list
    - Route longName in typography.headlineLG (32pt Manrope Bold)
    - Favorite star (MaterialIcons 'star-border') on the right — calls showToast('Coming soon') per Phase 1 placeholder pattern
    - Min height 56px, padding consistent with EDGE_MARGIN
  - Stop list (NOT a FlatList — use plain View since stop counts are small, typically 4-15 per route):
    - Map over stops array with index for sequenceNumber (1-based)
    - Render StopRow for each stop
    - Pass isSelected={stop.stopId === selectedStopId}

- ETA derivation logic (in RouteDetailView, memoized with useMemo):
  - Filter vehicles.positions to those matching selectedRouteId
  - For each stop in the route's stop list, find all vehicles whose nextStopId matches this stop's stopId
  - For each matching vehicle, take its etaSeconds and format:
    - etaSeconds < 60 → "< 1 min"
    - etaSeconds >= 60 → `${Math.round(etaSeconds / 60)} min`
  - Join formatted ETAs with " \u00B7 " (middle dot with spaces)
  - If no vehicles match this stop → "No buses en route"
  - This naturally refreshes every 5s because vehicles.positions updates from the polling hook
  - Sort ETAs ascending before joining (shortest arrival first)

- Stop tap handler: dispatch selectStop(stopId) on press. If same stop tapped again, dispatch selectStop(null) to deselect.

- Back button handler: dispatch selectRoute(null) AND selectStop(null) to clear both selections.
