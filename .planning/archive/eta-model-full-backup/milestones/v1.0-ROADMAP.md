# Milestone v1.0: XGBoost ETA Model

**Status:** SHIPPED 2026-02-11
**Phases:** 1-6
**Total Plans:** 13 (06-02 skipped)

## Overview

Build an XGBoost-based ETA prediction model for Auburn's Tiger Transit system, replacing the existing PyTorch neural network. The roadmap follows an incremental approach: establish reliable data pipelines first, train a baseline model on core features, layer on differentiator features (timepoints, rolling speeds, historical stats), optimize training with asymmetric loss and hyperparameter tuning, then validate thoroughly with sliced metrics and SHAP analysis. Every phase produces a verifiable artifact -- no phase ends without something you can run and check.

## Milestone Summary

**Key Decisions:**

- XGBoost over PyTorch for tabular transit ETA (faster training, interpretable, no GPU needed)
- Single model for all routes (route encoded as categorical feature)
- Per-stop row explosion (each observation x remaining stops = N rows)
- Chunked-by-day Parquet processing to avoid OOM
- merge_asof(forward, 2h tolerance) for ground truth labels (88.8% success)
- Temporal split by calendar date with 1-day gap (no random splitting)
- pred_contribs over TreeExplainer for SHAP (2158-iteration model too slow)
- Quantile-based distance bucketing (all distances < 7 km)
- 3:1 asymmetric loss with 8-minute proximity scaling
- Optuna 50 trials on 10% subsample, retrain on full data

**Issues Resolved:**

- Timepoint Excel mapping: 27/28 stops matched via fuzzy matching + manual overrides
- Label join success rate: 88.8% (well above 60% minimum)
- Model under-training at 3000 rounds: Optuna found optimal lr=0.201, 1239 rounds
- Distance bucketing: Quantile-based thresholds replaced meter-based (all distances < 7 km)
- TreeExplainer timeout: pred_contribs provides equivalent exact SHAP values natively

**Issues Deferred:**

- Quantile monotonicity violations (32.3%) -- consider joint quantile training
- Route 27 insufficient data (96 samples, 336.9s MAE)
- Route-specific calibration for biased routes (6 over, 2 under)
- Midday overprediction bias (+24.93s)
- lateness_now has zero variance in EtaSpot data (scheduled_eta == eta)

**Technical Debt Incurred:**

- Phase 3 features inlined in v2 pipeline (04-02) for self-contained execution
- Quantile models trained on 25% subsample (full data may improve monotonicity)
- 06-02 human review plan skipped (evaluation artifacts not visually verified)
