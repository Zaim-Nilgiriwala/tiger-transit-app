  <name>Task 1: Generate timepoint-to-GTFS mapping draft</name>
  <files>scripts/generate_timepoint_mapping.py, data/processed/timepoint_mapping.json</files>
  <action>
Create `scripts/generate_timepoint_mapping.py` that:

1. **Extracts all unique timepoint stop names** from the timepoint Excel file at `mobile/src/ETA-Model/raw_data/Tiger_Transit_Timepoints_Fall2025.xlsx`. Open with `openpyxl.load_workbook(data_only=True)`. For each of the 23 sheets, read row index 1 (0-indexed) to get timepoint stop names. Collect all unique non-None, non-empty string names.

2. **Loads GTFS stop names** from `mobile/src/ETA-Model/stops.json`. Build a dict of `{name: id}` for all stops.

3. **Attempts matching** for each unique timepoint name:
   - First: exact match against stops.json names
   - Second: case-insensitive exact match
   - Third: `difflib.get_close_matches(timepoint_name, stop_names, n=3, cutoff=0.5)` to find fuzzy candidates
   - Record the match type (exact, case-insensitive, fuzzy, unmatched) for each

4. **Writes draft mapping** to `data/processed/timepoint_mapping.json` as:
   ```json
   {
     "timepoint_name": {
       "stop_id": 123,
       "stop_name": "Matched GTFS Stop Name",
       "match_type": "exact|fuzzy|unmatched",
       "confidence": "high|medium|low",
       "alternatives": ["Alt Name 1", "Alt Name 2"]
     }
   }
   ```
   For unmatched names (like "HUB", "Museum"), set `stop_id` to `null` and list the top 3 fuzzy candidates in `alternatives`.

5. **Prints a review table** to stdout showing each timepoint name, its proposed match, match type, and confidence. Format clearly for user review:
   ```
   TIMEPOINT MAPPING DRAFT - REVIEW REQUIRED
   ==========================================
   [EXACT]  "Tiger Transit Hub" -> "Tiger Transit Hub" (stop_id: 45)
   [FUZZY]  "Peachtree Apts" -> "Peachtree Apartments" (stop_id: 78) -- confidence: high
   [NONE]   "HUB" -> ??? -- candidates: ["Tiger Transit Hub", "Hub Parking", ...]
   ```

6. Also extract which sheet (route) each timepoint name appears on, and print that association so the user has context for the ambiguous names.

Use `PROJECT_ROOT = Path(__file__).resolve().parent.parent`.

<task type="auto">
  <name>Task 3: Create timepoint parser script</name>
  <files>scripts/parse_timepoints.py, data/processed/timepoints.parquet</files>
  <action>
Create `scripts/parse_timepoints.py` that:

1. **Loads the verified mapping** from `data/processed/timepoint_mapping.json`. If the file doesn't exist, print an error message saying to run `generate_timepoint_mapping.py` first and have the user review it, then exit.

2. **Opens the timepoint Excel** with `openpyxl.load_workbook(data_only=True)`.

3. **Parses each of the 23 sheets**. For each sheet:
   - Read all rows via `ws.iter_rows(values_only=True)`
   - Row 0 contains description strings (route variant info like "South Donahue 1 starts at 7:00 ends at 20:00 Stages at The Mill")
   - Row 1 contains timepoint stop names
   - Row 2+ contains scheduled times as `datetime.time` objects

   **Detect column groups**: Timepoint pairs are separated by None/blank columns. Walk across row 1, grouping consecutive non-None columns. Each group typically has 2 columns (departure stop, arrival stop for a route segment).

   **For each column group**, for each time row (row 2+), for each column in the group:
   - If the cell value is a `datetime.time` object, record a tuple
   - Skip None cells (gaps in schedule)

4. **Maps names to IDs** using the verified mapping:
   - Look up each timepoint stop name in the mapping
   - If mapping has a valid stop_id, use it
   - If stop_id is null (unmatched), log a warning and skip that timepoint
   - Extract route info from the sheet name (which corresponds to a route)

5. **Maps sheet names to route IDs**: Load `gtfs_data/routes.txt` to build a route_long_name -> route_id_num mapping. Sheet names correspond to route names. If a sheet name doesn't match exactly, try fuzzy matching.

6. **Builds output DataFrame** with columns:
   - `route_id` (numeric, from GTFS)
   - `route_name` (sheet name, for reference)
   - `stop_id` (numeric, from mapping)
   - `stop_name` (original timepoint name, for reference)
   - `scheduled_time` (time string "HH:MM:SS" format)

7. **Prints validation summary**: Total tuples, unique routes, unique stops, tuples per route, any skipped timepoints with reasons.

8. **Writes** to `data/processed/timepoints.parquet`.

Important: The Excel has irregular layout -- don't assume fixed column positions. Detect groups dynamically. Some sheets may have 2, 3, or more sub-tables side by side.
  </action>
